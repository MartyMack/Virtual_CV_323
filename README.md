# Virtual_CV_323

========================================================================
                      VIRTUAL CV / DEVELOPER PORTFOLIO
========================================================================

PROJECT OVERVIEW
----------------
This project is a modern, single-page interactive developer portfolio 
inspired by minimalist aesthetic layouts (notably Pratibha Joshi's portfolio), 
customized with an Orange & White / Dark Mode color scheme.

FEATURES
--------
1. Single-Page Application (SPA) Architecture:
   - Dynamic view switching between content panels (Home, About/CV, Skills, 
     Projects, Contact Me) using lightweight Vanilla JavaScript.
   - Smooth entrance animations (slideUpFade) without page reloads.

2. Dark / Light Mode Engine:
   - Defaults to Dark Mode on page load.
   - Smooth CSS background and text color transitions.
   - Interactive theme toggle button with custom pop-and-rotate animation.

3. Responsive Two-Column Layouts:
   - Content panels feature a side-by-side arrangement (text on left, 
     curated imagery on right).
   - Fully responsive design using modern CSS Flexbox, Grid, and @media queries.
   - Automatically stacks content vertically for optimal reading on mobile devices.

4. Legal Open-Source Imagery:
   - Utilizes royalty-free imagery sourced directly from Unsplash.
   - Avatar photo frame ready for personal image replacement.

FILE STRUCTURE
--------------
/
├── index.html     - Main entry point containing structural HTML, CSS variables,
│                    responsive styles, and view-switching JavaScript logic.

TECHS USED
